# LLM-Final：狼人杀互动视频脚本创作助手
本项目旨在帮助用户快速创建狼人杀互动视频脚本，提供从角色分配、台词生成到情节发展的全方位辅助。通过 Python 编写，结合机器学习和自然语言处理技术，打造高效、智能的脚本创作工具。

## 项目功能

- **角色分配与生成**：基于游戏规则和角色需求，自动分配角色并生成描述。
- **台词与互动生成**：结合预设情节和角色特点，自动生成符合逻辑的台词与互动。
- **多轮讨论模拟**：支持多轮发言模拟，帮助设计丰富的剧情分支。
- **随机事件设计**：提供可选的随机事件生成模块，为剧本添加不确定性和趣味性。

## 配制环境
运行本项目需要openai，scikit-learn，numpy库

## 使用方法

使用 LLM_Final 代码，请按照以下步骤操作：

1. 进入项目目录：`cd LLM_Final`

2. 在 `src/test/` 目录下运行示例场景的主脚本。
   
您可以在`src/config/`目录下修改游戏的人物及角色配置
